## 🎯 Key Themes Across the Series

- **SOC Tiers:** L1 (Triage) → L2 (Investigation) → L3 (Threat Hunting) → SOC Manager → SOC Director
- **Core Loop:** Monitor → Detect → Analyze → Respond
- **L1 Golden Rules:** Never ignore alerts · Never delete logs · Never take unauthorized action · Never escalate without analysis · Never skip documentation
- **Threat Intel Toolkit:** VirusTotal, AbuseIPDB, WHOIS, ASN/AMASS
- **Frameworks:** CIA Triad, Cyber Kill Chain (7 phases), Defense-in-Depth
